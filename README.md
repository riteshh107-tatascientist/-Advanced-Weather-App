# 🌦️ Weather Forecast App

## 📌 Overview

This project is a **Weather Forecast Application** that provides real-time weather information for any city using API integration.
It helps users check temperature, humidity, weather conditions, and more instantly.

---

## 🚀 Features

* 🌍 Search weather by city name
* 🌡️ Real-time temperature display
* 💧 Humidity and pressure details
* ☁️ Weather condition (Cloudy, Sunny, Rainy, etc.)
* ⚡ Fast and responsive UI

---

## 🛠️ Tech Stack

* Python 🐍
* Streamlit (UI)
* OpenWeather API 🌐
* Requests library

```bash id="wth234"

```

---

### 2️⃣ Install Dependencies

```bash id="wth345"
pip install -r requirements.txt
```

---

### 3️⃣ Add API Key

* Go to https://openweathermap.org/api
* Create a free API key
* Add it in your code:

```python id="wth456"

```

---

### 4️⃣ Run the App

```bash id="wth567"
streamlit run app.py
```
